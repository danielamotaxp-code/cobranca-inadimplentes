# Cobrança Inadimplentes · código da página

Página **Cobrança Inadimplentes** da [Plataforma](https://danielamotaxp-code.github.io/central-atendimento/#cobranca). Ela abre dentro do portal, com o login, as permissões e as cores de lá.

| | |
|---|---|
| Endereço | [https://danielamotaxp-code.github.io/central-atendimento/#cobranca](https://danielamotaxp-code.github.io/central-atendimento/#cobranca) (o endereço antigo deste repositório redireciona para lá) |
| Página | `app.html` (código público, sem dados de clientes) |
| Dados | repositório privado `cobranca-acessos` |
| Ligação com o portal | `<script src="/central-atendimento/kit/modulo.js" data-modulo="cobranca">` no início do `app.html` |
| Cores | `embutido.css` (WeGen verde, SmartBen azul, WattWise rosa) |
